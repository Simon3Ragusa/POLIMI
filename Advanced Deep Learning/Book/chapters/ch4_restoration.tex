\section{Introduction to Image Denoising}
Image restoration, and specifically image denoising, is a fundamental problem in computer vision and image processing. It acts as a crucial pre-processing step in various imaging pipelines to enhance output quality and improve the effectiveness of subsequent algorithms, a post-processing technique to remove compression artifacts (e.g., blockiness and ringing), and a plug-and-play filter for implicit regularization in various inverse problems and imaging applications.

\subsection{The Observation Model}
The classic degradation model for image denoising formulates the observed noisy image as the superposition of a clean signal and additive noise. Formally, let $X$ denote the domain of the image. The observation model is defined as:
\begin{equation}
    z(x) = y(x) + \eta(x), \quad x \in X
\end{equation}
where $z: X \to \mathbb{R}$ is the observed noisy image, $y: X \to \mathbb{R}$ is the unknown original clean image (e.g., grayscale), and $\eta: X \to \mathbb{R}$ represents the noise perturbation. In many theoretical analyses and standard benchmarks, $\eta$ is modeled as independent and identically distributed (i.i.d.) Additive White Gaussian Noise (AWGN), such that $\eta \sim \mathcal{N}(0, \sigma^2)$, with $\sigma^2$ being the noise variance. 

The primary goal of any denoising algorithm is to provide an estimate $\hat{y}$ of the original image $y$, effectively reversing the ill-posed degradation process. This objective extends seamlessly to RGB images, where the corruption affects all three color channels. 

\begin{insightbox}[Denoising as a Supervised or Unsupervised Learning Problem]
Is denoising using deep neural networks a supervised or unsupervised learning problem?
\begin{itemize}
    \item \textbf{Supervised:} The loss function is typical of supervised learning, e.g., the Mean Squared Error (MSE) $||\hat{y} - y||_2^2$, which assumes the availability of the noise-free ground truth image $y$.
    \item \textbf{Unsupervised:} It resembles unsupervised learning since no explicit semantic labels or manual annotations are required for training.
    \item \textbf{Self-Supervised:} It aligns with self-supervised learning as we can easily generate annotated pairs by artificially corrupting clean images. However, unlike standard self-supervised pre-training, the auxiliary task (denoising) is already our ultimate goal.
\end{itemize}
Supervised training of a neural network to directly reduce a loss function has yielded substantial performance improvements over traditional denoising algorithms, which heavily relied on statistical modeling of the input signal and the noise distribution.
\end{insightbox}

\section{Simple Deep Neural Networks for Image Denoising}

\subsection{Straightforward Solutions and Their Limits}
A straightforward approach to image denoising is to adopt a Convolutional Neural Network (CNN) architecture with identical input and output spatial dimensions, akin to architectures used for semantic segmentation. The training data comprises pairs of images: $TR = \{(y, z)\}$, where $y$ is a natural clean image and $z$ is its noisy counterpart. Gathering a vast training dataset $TR$ is easy, given that the forward model (the physical laws or sensor characteristics simulating the noise) is known. By applying this forward model to clean images, we synthesize the noisy inputs. 

The inverse pass, however, is ill-posed and unknown. As long as the forward model is known and realistic, and the CNN can be trained effectively, this exact same procedure can be applied to various types of perturbations, including denoising, deblocking, deblurring, super-resolution, inpainting, enhancement, and de-raining.

\subsection{DnCNN: Residual Learning of Deep CNNs}
The DnCNN (Denoising Convolutional Neural Network) architecture introduced a paradigm shift by leveraging residual learning. Instead of directly predicting the clean image $\hat{y}$, the network is trained to predict the noise realization $\hat{\eta}$. 

Given the observation $TR = \{(z, \eta), z = y + \eta\}$, the network output is formulated as:
\begin{equation}
    \hat{y} = z - \hat{\eta} = z - \text{CNN}(z)
\end{equation}
It is empirically and theoretically easier to optimize the loss function over the high-frequency noise $||\eta - \text{CNN}(z)||_2$ rather than directly on the low-frequency image content.

\subsubsection{Architecture Details}
The DnCNN is a Fully Convolutional Neural Network (FCNN) composed of $d$ layers:
\begin{itemize}
    \item \textbf{Layer 1:} A Convolutional layer followed by a ReLU activation function. It uses 64 filters of size $3 \times 3 \times c$, where $c$ is the number of image channels.
    \item \textbf{Layers 2 to $d-1$:} A combination of Convolution, Batch Normalization (BN), and ReLU. Each layer applies 64 filters of size $3 \times 3 \times 64$.
    \item \textbf{Layer $d$:} A single Convolutional layer with $c$ filters of size $3 \times 3 \times 64$ used to reconstruct the input noise.
\end{itemize}
To handle border artifacts, the input image is zero-padded outside the image before processing. 

\subsubsection{Loss Function and Training}
The network is trained to estimate the noise realizations in images by minimizing the residual loss:
\begin{equation}
    \ell(\Theta) = \frac{1}{2N} \sum_{i=1}^N || \text{CNN}(z_i, \Theta) - (z_i - y_i) ||_F^2
\end{equation}
where $\Theta$ represents the learnable parameters. Training samples are easy to generate by adding synthetic, realistic noise to clean images. To ease the training process and reduce memory overhead, the loss is assessed on small patches cropped from the noisy images. Since the network is fully convolutional, it can be seamlessly applied to images of arbitrary sizes during inference. 

A typical training set consists of 400 images of $180 \times 180$ pixels (larger training sets do not improve performance substantially). Network training is performed patch-wise: $40 \times 40$ patches are used for Gaussian denoising, and $50 \times 50$ patches for other denoising problems. To achieve robustness, the training is repeated by corrupting the training images with different noise levels $\sigma$. The denoising tasks targeted include AWGN (with known and unknown variance), bicubic upsampling (Super-resolution), and JPEG compression.

\subsubsection{Limitations of DnCNN}
Despite its success, DnCNN has significant limitations. The network learns a mapping function $z \to \mathcal{F}(\Theta_\sigma, z)$, where the optimal parameters $\Theta_\sigma$ depend entirely on $\sigma$, the noise standard deviation encountered during training. Consequently, a standard DnCNN is hard to be deployed to images corrupted by: different noise levels, different noise models, or spatially variant / signal dependent noise.

\section{Handling Complex Noise Models: FFDNet}
To overcome the inflexibility of DnCNN, FFDNet (Fast and Flexible Denoising Network) introduces a mechanism to handle varying noise levels within a single unified architecture. FFDNet learns a mapping function:
\begin{equation}
    z \to \mathcal{F}(\Theta, z, M)
\end{equation}
Crucially, the network parameters $\Theta$ do not depend on the specific noise parameters. Instead, the noise characteristics are explicitly fed into the network as an additional input map $M$.

\subsection{Input Preparation and Pixel Shuffling}
For an input image of size $W \times H \times C$, the network takes two distinct inputs:
\begin{enumerate}
    \item A \textbf{noise level-map $M$}, which reports in each pixel the noise standard deviation over $z$. For Additive White Gaussian Noise (AWGN), $M$ corresponds to a uniform image equal to the noise std $\sigma$. In the case of spatial-variant noise, $M$ is a non-uniform image defined by the noisy image $z$ and the sensor characteristics. It enables using a single model for different values of $\sigma$ without the need to retrain.
    \item \textbf{Downsampled Sub-images}: To increase the receptive field and reduce computational complexity in all convolutional layers after the first one, the input image undergoes a "pixel shuffle" (downsampling) operation. The image is decomposed into 4 downsampled and cropped images having size $\frac{W}{2} \times \frac{H}{2} \times C$, stacked in different channels. Downsampling is indeed shuffling of the image among channels.
\end{enumerate}
Therefore, the effective input has the size $\frac{W}{2} \times \frac{H}{2} \times (4C + 1)$. This resizing step significantly reduces the spatial extent of the feature maps. The output is then subjected to an upsampling operation to reconstruct the original $W \times H \times C$ shape.

\subsection{Architecture and Loss Formulation}
The core architecture consists of an input preparation stage, a non-linear mapping stage (comprising multiple Conv+ReLU and Conv+BN+ReLU blocks), and an upsampling stage. Like DnCNN, all convolutions are $3 \times 3$. The depth level $d$ and the number of filters per layer depend on the image type:
\begin{itemize}
    \item \textbf{Grayscale images:} Depth level $d=15$, with 64 filters per layer.
    \item \textbf{Color images:} Depth level $d=12$, with 96 filters per layer.
\end{itemize}
The design is driven by performance and "heuristic criteria": using lower values of $d$ in color images helps to better exploit the correlation among R, G, B channels.

The loss to minimize assesses how good the network can estimate noise-free patches. It uses the Frobenius norm, which is the $\ell^2$ norm for matrix entries:
\begin{equation}
    \ell(\Theta) = \frac{1}{2N} \sum_{i=1}^N || \mathcal{F}(z_i, \Theta, M) - y_i ||_F^2
\end{equation}
Patch-wise training is utilized. There is no need to train using heterogeneous noise maps; the fully convolutional network can successfully operate on locally uniform noise maps. The patch sizes are $50 \times 50$ for grayscale and $70 \times 70$ for color. FFDNet achieves comparable performance to DnCNN on datasets like BSD68 with noise levels 15, 25, 35, 50, and 75, often slightly outperforming or matching the baseline.

\begin{insightbox}[The Impact of Mismatched Noise Estimates in FFDNet]
What happens if the noise level map $M$ provided to FFDNet is inaccurate?
For all the denoisers:
\begin{itemize}
    \item \textbf{Using higher $\sigma$ than the true one:} Results in over-smoothing. Thus, the PSNR is constant but does not reach the same optimal level as when the noise level is perfectly correct.
    \item \textbf{Using lower $\sigma$ than the true one:} Results in noisy outputs. Thus, this critically decreases the overall PSNR.
\end{itemize}
\end{insightbox}

\subsection{Generalization via Bias-Free Networks}
An important advantage of deep-learning techniques over traditional methodology is that a single neural network can be trained to perform denoising at a wide range of noise levels. However, empirical evidence shows that current state-of-the-art architectures systematically overfit to the specific noise levels in the training set, performing very poorly at new noise levels. 

Generalization can be remarkably achieved through a simple architectural modification: removing all additive constants. "Bias-free" CNNs attain state-of-the-art performance over a broad range of noise levels, even when they are explicitly trained over a much narrower range. The training plots for Bias-Free CNNs display robust PSNR slopes that perfectly extrapolate beyond the training range, outperforming standard networks that rapidly degrade in generalization capability outside the shaded training region.

\section{Class-Aware Denoising}
Image statistics vary drastically depending on the semantic content of the image. A network trained to denoise natural landscapes might struggle to reconstruct the specific high-frequency textures of a human face. Class-Aware Denoising aims to improve the prior on images: narrow down the space of images and train a specialized network for a specific class of images.

\subsection{Gradual Denoising and Architecture}
A typical class-aware network utilizes a Fully Convolutional architecture to enable denoising of images having different sizes, promoting fast execution and a relatively low number of parameters. The core operational mechanism is \textit{gradual denoising} as the volume circulates through the network. 

The architecture incorporates multiple long skip connections. The noisy input is added to the networks' "gradual" outputs across the depth of the model. These outputs are considered as noise-estimates because they sum to the noisy input, and the result cancels out the noise. Typically, 20 of such layers are stacked in this network.

Visualizing these intermediate noise estimates is possible and reveals the internal logic:
\begin{itemize}
    \item \textbf{Shallower layers} seem to handle finer details and noise.
    \item \textbf{Deeper layers} seem to recover edges and texture that might get lost during the aggressive filtering at the first layers. This is due to the larger receptive field of deep layers, that enable them to distinguish structural edges and structures from random noise.
\end{itemize}

During training, different networks are trained for specific classes of images using the exact same FCNN architecture. Common classes include: face, pet, flower, living room, street. During testing, one must first estimate the class from a secondary classification CNN, and then dynamically apply the corresponding specialized denoising network.

\section{Self-Supervised Image Denoising}
A fundamental limitation of supervised image denoisers is their strict requirement for vast datasets of perfectly aligned noisy-clean image pairs. In many real-world applications, acquiring clean images is physically impossible or highly impractical. For instance:
\begin{itemize}
    \item \textbf{Medical imaging:} In CT scans, to reduce radiation exposure, we are forced to acquire fewer and fundamentally noisier images.
    \item \textbf{Outdoor photography:} Long exposure times or averaging several images of the same scene presents obvious problems in dynamic, moving scenes.
\end{itemize}
Self-supervised image denoising totally removes the need for clean images, opening the possibility for denoising in many more critical applications.

\subsection{Noise2Noise (N2N): Learning without Clean Data}
The Noise2Noise (N2N) framework demonstrated that one could learn image restoration without ever seeing a clean image. For each training sample, instead of a noisy-clean pair $(z, y)$, N2N requires two independent noisy realizations of the exact same underlying scene: $(z, y)$ denoisers are traditionally trained to minimize:
\begin{equation}
    \Theta^* = \text{argmin}_\Theta \mathbb{E} [\mathcal{L}(\text{CNN}(\Theta; z), y)]
\end{equation}
Typically $\mathcal{L}$ is the MSE, or the $\ell_1$ norm, or $SSIM(\cdot, \cdot)$.

The core Idea: As long as the noise is zero-mean and independent between the two noisy realizations of the same image, $z = y + \eta$ and $z' = y + \eta'$, we can replace $y$ with a different noise realization $z'$ and optimize:
\begin{equation}
    \Theta^* = \text{argmin}_\Theta \mathbb{E}_{z,z'} [\mathcal{L}(\text{CNN}(\Theta; z), z')]
\end{equation}
On average, the optimal function learned by the network still robustly predicts the clean signal $y$. 

The advantages are massive: there is no need for noise-free images, nor is there a need for an explicit noise model to perturb images. It practically proved that it is possible to learn denoising without clean images. The primary problem is that it still needs pairs of images of the same underlying scene, which might be completely unpractical in some applications (like CT scans).

\subsection{Noise2Void (N2V) and Blind-Spot Networks}
Noise2Void (N2V) solves the dual-image requirement by learning denoising directly from a training set of \textit{unpaired single noisy images}. 

\subsubsection{The Identity Function Problem}
If one simply feeds a noisy image $z$ as both the input and the target:
\begin{equation}
    \Theta^* = \text{argmin}_\Theta \mathbb{E}_z [\mathcal{L}(\text{CNN}(\Theta; z), z)]
\end{equation}
This leads the model to critically learning the identity function ($\text{CNN}(z) = z$), perfectly reconstructing the noise rather than attempting to remove it.

\subsubsection{The Blind-Spot Network (BSN) Framework}
The solution is the Blind-Spot Network (BSN) training framework. The core BSN Framework Idea is to hide some pixels in the receptive field of the network (blind spots). 
Input: $z$ with blind spots.
Target: $z$ noisy.
Train to minimize loss function:
\begin{equation}
    \Theta^* = \text{argmin}_\Theta \mathcal{L}(\text{CNN}(\Theta; z), z)
\end{equation}

The underlying assumption is two-fold:
\begin{enumerate}
    \item The noise-free image $y$ has strong spatial correlation.
    \item The noise is pixel-wise independent and strictly zero-mean.
\end{enumerate}
Consequently, the network learns the clean values of the blind spots using only information coming from the outer receptive field.

There are two primary ways to construct a BSN:
\begin{enumerate}
    \item \textbf{Designing a specific network architecture:} Generating physical blind spots in the receptive field. Examples are Half-plane convolutions (convolutions on half-planes to omit the central pixel) and Dilated convolutions equipped with explicitly designed holes in the filter center.
    \item \textbf{The N2V way:} Apply a masker, a function that replaces (masks) some pixels of the input image, as a strict preprocessing step before feeding the image to the network. N2V proposes deciding the new blind-spot (BS) value via:
    \begin{itemize}
        \item Value of a random pixel in the immediate neighborhood of the BS.
        \item Mean of a small region centered perfectly in the BS.
        \item Median of a small region centered in the BS.
        \item Replace with a purely random value.
    \end{itemize}
\end{enumerate}

In this masking case, it is absolutely better to focus the loss directly on the blind spots. Hence, the loss function becomes an error assessed only at the central masked pixels:
\begin{equation}
    \Theta^* = \text{argmin}_\Theta \mathcal{L}(B .* \text{CNN}(\Theta; M(z)), B .* z)
\end{equation}
where $M(z)$ is the masked input and $B .* z$ represents the target image evaluated solely at the selected locations.

\section{Concluding Remarks}
The research activity in the field of CNNs for image restoration has become very vivid in the last few years. The performance improvement achieved by deep CNNs was not as instantaneously clear as for visual recognition problems, but now these achieve the undisputed state of the art in terms of raw performance. Still, traditional algorithms are often more efficient. This is crucial given the large image sizes (compared to standard visual recognition benchmarks).

Architecture of denoisers are becoming more and more complex. Research directions now heavily include efficient solutions, practical training options (without using an artificial noise model or clean pristine images), and overall robustness to diverse noise models.

Research is often deeply inspired by traditional priors, meticulously designing neural architectures able to promote these:
\begin{itemize}
    \item Self-similarity
    \item Sparsity
    \item Multiscale processing
\end{itemize}
CNNs are now more recently used as a powerful prior for natural images, often placed inside iterative denoising schemes such as Residual Unfolding Networks. Often performance is heavily influenced by the raw training power, offering essentially unlimited training data thanks to BSN.

Finally, approaches like CBDNet aim to close the gap toward convolutional blind denoising of real photographs. Existing CNN denoisers tend to be over-fitted to simplistic Gaussian noise and generalize poorly to real-world noisy images with more sophisticated noise. Realistic noise models are the foremost issue for blind denoising of real photographs. By taking into account both the Poisson-Gaussian model and the entire in-camera processing pipeline (e.g. de-mosaicking, Gamma correction, and JPEG compression), CBDNet utilizes two subnetworks (noise estimation and non-blind denoising), adopts an asymmetric loss by imposing more penalty on under-estimation error of the noise level, and routes information through a tightly constrained bottleneck.

\subsection{Possible Exam Questions}
\begin{itemize}
    \item \textbf{Q: Explain the fundamental observation model for image denoising and define the roles of the clean signal and additive noise.} \\
    \textbf{A:} The observation model is $z(x) = y(x) + \eta(x)$, where $z(x)$ is the observed noisy image, $y(x)$ is the unknown original clean image, and $\eta(x)$ is the additive noise (often modeled as AWGN). The goal is to estimate $y(x)$ to reverse the degradation.
    
    \item \textbf{Q: Discuss how image denoising using neural networks bridges the gap between supervised and self-supervised learning.} \\
    \textbf{A:} It uses a supervised loss (e.g., MSE against a ground truth), requires no manual semantic annotations (like unsupervised learning), and aligns with self-supervised learning since training pairs can be generated automatically by artificially adding noise to clean images.
    
    \item \textbf{Q: Describe the architecture of DnCNN and explain why predicting the noise residual is advantageous over predicting the clean image.} \\
    \textbf{A:} DnCNN is a Fully Convolutional Neural Network composed of Conv+ReLU, Conv+BN+ReLU layers. It uses residual learning to predict the noise $\hat{\eta}$, reconstructing the image as $\hat{y} = z - \hat{\eta}$. This is advantageous because optimizing the mapping over high-frequency noise is empirically and theoretically easier than directly reconstructing low-frequency image content.
    
    \item \textbf{Q: What are the main limitations of DnCNN, and how does FFDNet overcome them using a noise level map and pixel shuffling?} \\
    \textbf{A:} DnCNN overfits to the specific noise variance $\sigma$ seen during training. FFDNet overcomes this by taking a noise level map $M$ as an additional input, making the network parameters independent of a specific $\sigma$. It also uses pixel shuffling to downsample the input into sub-images, increasing the receptive field and computational efficiency.
    
    \item \textbf{Q: Analyze the impact of providing an inaccurate noise level estimate (either too high or too low) to FFDNet.} \\
    \textbf{A:} Providing a higher $\sigma$ than the true noise level results in over-smoothing (PSNR plateaus suboptimally). Providing a lower $\sigma$ than the true noise level leads to noisy outputs and critically decreases the PSNR.
    
    \item \textbf{Q: Explain the concept of Class-Aware Denoising and the mechanism of gradual denoising across network layers.} \\
    \textbf{A:} Class-Aware Denoising trains specialized networks for specific image domains (e.g., faces) to narrow down the space of possible images. Gradual denoising utilizes long skip connections to add the noisy input to intermediate layers, canceling noise progressively where shallow layers handle fine details and deep layers recover structure.
    
    \item \textbf{Q: How does the Noise2Noise framework eliminate the need for clean target images, and what are its core assumptions?} \\
    \textbf{A:} Noise2Noise trains a network to map a noisy observation to a different, independent noisy observation of the exact same scene. It assumes the noise is zero-mean and independent between the two realizations, allowing the network to robustly predict the underlying clean signal on average.
    
    \item \textbf{Q: Describe the Identity Function problem encountered when training denoisers on single noisy images.} \\
    \textbf{A:} If a network is trained to map a single noisy image $z$ to itself as the target, it will simply learn the identity function ($\text{CNN}(z) = z$), perfectly reconstructing the noise rather than learning how to remove it.
    
    \item \textbf{Q: How does Noise2Void (N2V) utilize Blind-Spot Networks (BSN) to solve the identity function problem?} \\
    \textbf{A:} N2V masks or hides the central pixel (blind spot) in the network's receptive field. The network is forced to estimate the value of the blind spot using only the outer spatial context. Assuming noise is pixel-wise independent and the image has spatial correlation, it learns the clean signal without copying the noise.
    
    \item \textbf{Q: Compare the practical applicability of supervised denoising models versus self-supervised models in fields like medical imaging.} \\
    \textbf{A:} Supervised models require vast datasets of perfectly aligned noisy-clean pairs, which is physically impractical or unsafe (e.g., high radiation in CT scans). Self-supervised models like N2N and N2V can train directly on noisy data, enabling effective denoising in critical applications without needing clean references.
\end{itemize}
