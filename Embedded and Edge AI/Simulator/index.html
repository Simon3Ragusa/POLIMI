Section 1: Closed Questions

1. Which quantization technique requires a calibration dataset?
  • A. Dynamic Range Quantization
  • B. Post-Training Integer Quantization (PTQ)
  • C. Float16 Quantization
  • D. None of the above
Correct Answer: B. PTQ requires a representative dataset to calibrate the dynamic range of activations.
2. True or False: SqueezeNet uses Depthwise Separable Convolutions to reduce parameters.
  • True
  • False
Correct Answer: False. SqueezeNet uses "Fire Modules" (1x1 squeeze and 1x1/3x3 expand). MobileNet uses Depthwise Separable Convolutions.

Section 2: Open Questions

Q1: Calculate MACs for a Conv layer (3x3 kernel, 64 input channels, 128 output channels, 32x32 input).
Solution:
Output size (no padding, stride 1): (32-3+1) = 30.
MACs = (Kernel_H * Kernel_W * Channels_In) * (Output_H * Output_W * Channels_Out)
MACs = (3 * 3 * 64) * (30 * 30 * 128) = 576 * 115,200 = 66,355,200 MACs.
Q2: Explain the "Early Exit" mechanism and its trade-offs.
Solution: Early Exit inserts classifiers at intermediate layers. If the confidence (e.g., entropy) is high enough, the inference stops early.
Trade-off: Lower latency and energy vs. potential drop in accuracy if the exit is too early or the threshold is poorly tuned.
Q3: Discuss the hardware limitations of ESP32-S3 for AI.
Solution:
- SRAM: ~512KB (shared with system).
- Flash: 4MB-16MB.
- AI Acceleration: SIMD instructions (PIE) but no dedicated NPU.
- Software: Supports TFLite Micro with optimized kernels for ESP-NN.
